# 송장 현황 도우미 개인정보처리방침

시행일: 2026-11-17
개발자: GB
문의: gbcompany.p@gmail.com

1. 처리 목적
사용자가 선택한 엑셀의 송장번호와 택배사를 이용해 ShipTrack에서 배송·통관 현황을 조회하고 결과 파일을 저장합니다. ShipTrack 또는 택배사가 제공하거나 보증하는 공식 제품이 아닌 독립 도구입니다.

2. 처리하는 정보
선택한 엑셀의 내용과 파일명, 송장번호, 택배사, 조회 결과, 처리 일시 및 오류 내역을 처리합니다. 파일을 읽는 과정에서 다른 열도 메모리에 포함될 수 있으므로 불필요한 개인정보는 제거하고 사용해 주세요.

3. 외부 전송
조회 시 송장번호와 택배사 선택이 HTTPS를 통해 track.shiptrack.co.kr에 전송됩니다. 요청 과정에서 IP 주소 등 일반적인 네트워크 정보도 해당 서비스에 전달됩니다. 엑셀 파일 전체를 외부 서버에 업로드하지 않습니다. 조회 요청에 저장된 로그인 쿠키를 포함하지 않습니다. 외부 서비스의 정보 보관과 삭제는 해당 서비스의 방침에 따릅니다.

4. 보관과 삭제
파일과 처리 결과는 작업 창의 메모리에서 처리하며 개발자 서버, 확장프로그램 저장소 또는 분석 서비스에 저장하지 않습니다. 작업 창을 닫으면 해당 창의 메모리 데이터는 해제됩니다. 다운로드한 파일은 사용자 기기에 남으며 직접 삭제할 수 있습니다. 확장프로그램을 삭제해도 다운로드 파일은 삭제되지 않습니다.

5. 이용 제한과 권한
데이터는 배송·통관 현황 조회와 결과 저장에만 이용합니다. 개발자는 데이터를 판매하거나 광고, 신용평가 또는 기능과 무관한 목적으로 이용하지 않습니다. 광고·분석 추적 도구를 포함하지 않습니다. 조회를 위해 https://track.shiptrack.co.kr/* 접근 권한을 사용합니다.

6. 문의와 변경
문의는 위 이메일로 보내 주세요. 문의 시 직접 제공한 정보는 이메일 서비스에서 문의 응대를 위해 처리될 수 있습니다. 불필요한 개인정보는 포함하지 마세요. 기능이나 정보 처리 방식이 변경되면 본 방침과 시행일을 갱신합니다.
